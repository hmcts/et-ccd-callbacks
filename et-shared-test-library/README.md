# et-shared-test-library

Minimal TypeScript + Node.js scaffold for shared test utilities that can be versioned and published for reuse across repositories.

## Quick start

```bash
npm install
npm test
```

## Publish flow

1. Update package metadata in `package.json` (name, version, license, repository).
2. Build and test:

```bash
npm test
```

3. Publish:

```bash
npm publish
```
